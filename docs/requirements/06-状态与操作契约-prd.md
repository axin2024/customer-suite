# 企业 CRM 与客户服务管理系统｜状态与操作契约

## 客户合同的生命周期

草拟→报价审批→已签→履约→续约或终止。归并客户不会合并合同，也不能改变历史签约主体。

## 权限与操作者

市场人员管理活动，销售只写分配客户，服务团队处理授权合同工单，部门经理看汇总，客户成功经理推进续约。 在待审批与已完成状态分别检查读写范围，委托与代办保留真实操作者身份。

## 两个关键交互

1. 线索输入来源号与身份线索，输出命中候选和归属；确定合并须有权限并可追踪原身份。
2. 服务事件输入合同、优先级及时间，输出受理队列、SLA 剩余量、暂停原因与升级级别。

## 业务操作与异常回执

| 操作域 | 在当前数据上的处理 | 冲突、拒绝或降级行为 |
|---|---|---|
| 客户主档 | 合并保留别名、外部来源和历史责任人，集团层级与服务数据授权分别维护。 | 合并同名但不同主体前提示识别证据不足。 |
| 营销与线索 | 保留首次与最近触点；手机号等标识须归一并按授权显示；认领竞争只产生一个有效负责人。 | 两销售同时认领，失败方能看到有效归属。 |
| 商机与预测 | 阶段推进校验决策人等必备信息，按货币与胜率生成时点预测，后续变化形成差异。 | 回退阶段不覆盖上期预测。 |
| 报价与合同 | 报价注明有效期及产品版本，超授权折扣须复核；已签版本归档并通过补充协议调整。 | 已过期报价须重报才可转合同。 |
| 交付交接 | 销售与实施共同确认范围，延期说明影响并登记待确认项目，验收记录绑定合同版本。 | 管理员变更负责人后旧人员失去写权限。 |
| 服务台 | 按合同服务级别计算响应及解决时限，等待客户时按规则暂停，超时只升级一次。 | 合同过期提示服务资格待复核并保留来单。 |
| 客户成功 | 健康度来源可回看，续约窗口生成唯一续约商机，负责人说明续约或流失的原因。 | 冻结客户标注风险并暂停自动触达。 |
| 经营分析 | 按阶段、组织和时点汇总，币种折算记录汇率，导出复用请求者可见范围。 | 分公司销售下载报表不含姐妹公司合同。 |

## 失联、中断及恢复

归并客户时锁双方主档并记录来源别名；按合同与续约周期唯一创建机会。索引按负责人、阶段、下次跟进日组织。 中断后先查询最后一个已持久的业务标记，再决定安全重试、补偿或人工复核。对外回执携带对象身份及业务版本。批量操作允许逐项查看成功、失败和未开始。

## 发布级业务断言

客户联系人同意范围可撤回，导出名单时重验；自动触达遵从渠道及客户当前状态。 A 的 60% 加权快照为 60 万；B 生成唯一续约任务；C 的工单按自身 SLA 计时，三个子公司互不可见。
