# 企业 CRM 与客户服务管理系统｜开源项目说明与首个案例

**customer-suite** 是面向自托管的 PHP 项目。统一客户身份连接营销、销售与售后，交付物为合同履约记录和可追溯经营预测。 本页作为后续公开使用手册的需求稿，实际发行时补入测试版本、安装入口与已验证的依赖组合。

## 准备

三家公司、虚构联系人、服务时钟与活动样例。

总部下辖三家公司，集团议价，三家分别签约；A 有 100 万商机，B 有将到期合同，C 提交服务请求。

## 第一次使用

1. 登记集团和三家公司，为每家公司分别分配销售和服务权限。
2. 市场重复导入同一线索并保留两个活动触点，销售将其转成 A 公司 100 万商机。
3. 按 60% 胜率冻结预测，给 B 公司生成一次到期续约，给 C 公司创建服务工单。
4. 切换到集团经理核对预测和三个主体的履约进度，再用 C 销售检验报表隔离。

## 对照综合样例

A 的 60% 加权快照为 60 万；B 生成唯一续约任务；C 的工单按自身 SLA 计时，三个子公司互不可见。 对照结果时保留源记录号、版本和操作时间，追踪从输入到最终交付的关联。

## 制造一次可恢复的异常

管理员变更负责人后旧人员失去写权限。回到对象详情核对 handover 和审计记录，再按指定版本恢复或重试。确认相同操作不会生成两份有效结果。

## 自托管与反馈

客户联系人同意范围可撤回，导出名单时重验；自动触达遵从渠道及客户当前状态。 提交问题请提供版本、最小合成输入、预期与实际结果。对接扩展可从以下方向开始：活动连接器、阶段校验及 SLA 日历扩展；示例联系人使用虚构身份。
