# 发行验收

[验收需求](requirements/04-验收与运营-prd.md) 的 16 个编号都对应到实际业务入口与测试脚本。下表所列集成用例在原生 PHP 8.2.30、MySQL 8.4.13、Windows 环境完成。渠道测试使用合成地址与本机 TLS。

| 验收编号 | 实测行为 | 复核入口 |
| --- | --- | --- |
| AC-01、AC-07、AC-08 | 集团报价按金额拆成三个法律主体。过期报价停止签约，更新报价后可继续。 | [合同](../tests/agreements.php) |
| AC-02、AC-03、AC-04 | 提示主体证据不足，重复线索保留两个活动触点，并发认领只生成一个有效归属。 | [主档和营销](../tests/accounts-marketing.php) |
| AC-05、AC-06 | 100 万元按 60% 得出 60 万元，回退阶段后保留上一快照数值。 | [商机与预测](../tests/sales.php) |
| AC-09、AC-10 | 甲验收后乙可继续独立办理。改派生效后旧交付负责人失去写权限。 | [交接与验收](../tests/handovers.php) |
| AC-11、AC-12 | 周五 17:50 来单在周一 09:20 截止首次响应；过期合同进入资格待复核并保留原来单。 | [服务台](../tests/service-desk.php) |
| AC-13、AC-14 | 并发扫描只建立一次续约，冻结客户时生成风险快照并阻断渠道调用。 | [续约与触达](../tests/customer-success.php) |
| AC-15、AC-16 | 集团经理按授权查看三家公司。分公司销售导出仅含自己授权的合同。 | [集团报表](../tests/management-reports.php)、[HTTP 工作台](../tests/http-workbench.php) |

## 独立启动、升级与恢复

- 用仅授权到独立库的 MySQL 应用账号完成空库迁移、创建管理员和样例导入。第二次导入返回同一回执。演示集成测试通过 30 项断言，五个示例岗位通过本机 HTTP 登录，并核对业务页面、所属范围 CSV、签收摘要和跨公司权限。见 [三公司演示](demo.md)。
- 对保留合成业务的 `009_management_reports` 数据库原地应用 `010_batch_jobs`。5 个报表快照、786 条审计事件及 8 个触达记录数量与升级前一致，健康检查返回 `ready`。
- 全量回归含 473 项 MySQL 与 HTTP 断言，另有 3 个 TLS 场景。工作台测试在操作回执返回前主动断开客户端，之后用相同标识恢复原回执。双执行器验证选集和业务版本在中断后的行为。见 [批量测试](../tests/batch-jobs.php) 与 [HTTP 测试](../tests/http-workbench.php)。
- 合成库的备份到空库过程逐字节核对了测试业务清单。源合同、历史报表和签收附件的验证步骤见 [备份恢复](backup-and-restore.md)。

## 客户与服务工单容量

在隔离 MySQL 演示库增加 10,000 个客户和 50,000 个工单，甲、丙各占一半。业务列表覆盖活动客户、已分队列的受理工单、服务岗位权限和游标翻页。8 个客户端各有独立会话，轮流请求 JSON、HTML 和四种跨公司访问。热身 8.20 秒，测量 30.27 秒。每个 HTTP 请求的测量时间包含连接与响应正文读取。

| 工作台入口 | 样本数 | p95（毫秒） |
| --- | ---: | ---: |
| 甲客户 JSON 列表 | 121 | 258.730 |
| 甲客户 HTML 列表 | 122 | 269.506 |
| 甲工单 JSON 列表 | 123 | 258.251 |
| 丙工单 JSON 列表 | 124 | 259.283 |
| 丙工单第二页 JSON | 124 | 257.570 |
| 丙工单 HTML 列表 | 124 | 274.443 |

共 1,228 次测量请求。四种越权输入共 490 次，均返回 404。客户端逐个核对返回记录或 HTML 标记，热身与测量窗口均未发现异常。环境为 Windows build 26200、22 个逻辑处理器、原生 PHP 8.2.30 单个 HTTP 进程和同机 MySQL 8.4.13。PHP 内存上限为 256 MiB，峰值工作集约 21.75 MiB。InnoDB 缓冲池为 128 MiB，MySQL 最大连接数为 151。这次测量覆盖同机工作列表和权限判定，工单使用合成合同与队列，未测跨主机链路、写入负载或高可用架构。

按 [演示教程](demo.md) 初始化名为 `crm_demo_capacity` 的隔离库。先为该环境导入样例，设置 `CRM_TEST_DATABASE=1`，启动连接该库的本机 Web 服务。将导入时使用的 `CRM_DEMO_PASSWORD` 提供给压测进程，再运行下面两条命令。

```sh
php tests/capacity-seed.php demo-admin@example.test > capacity-fixture.json
python3 -B tests/capacity-http.py capacity-fixture.json --url http://127.0.0.1:8081 --clients 8 --warmup 8 --seconds 30
```

负载脚本在每组至少取得 20 个有效样本、p95 不超过 2 秒且各窗口没有错误时返回成功。[原始测量 JSON](capacity-result.json)
