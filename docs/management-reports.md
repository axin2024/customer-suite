# 经营分析

「经营分析」提供历史商机阶段、转化漏斗、首次和最近触点归因以及签约金额。集团经理可纳入总部和有经理权限的直属公司，并从集团合计下钻到分公司、业务类型与阶段。

## 生成快照

1. 登记汇率版本，填写 UTC 汇率日、来源和各币种的折算值。例如 `{"USD":"7.12500000","JPY":"0.04750000"}`。单位为每一主单位外币折合人民币。CNY 固定为 1。单据按币种最小单位保存，折算时用十进制计算并在每条记录上四舍五入到人民币分。
2. 选择汇率版本、纳入公司和统计时点。时点可留空，默认取数据库当前 UTC 时刻。可选起始日用于限定商机建立和合同首次签署的时间。快照生成后保留源记录、时间、版本、渠道、原币金额与折算金额。币种缺少汇率时整次保存回滚。
3. 在公司和阶段分布中选择下钻入口。报表明细可以打开相应业务记录。导出沿用相同的公司、类型和阶段筛选，CSV 保留业务 ID、源阶段事件、金额版本、汇率和来源触点。

## 统计口径

- 当前阶段取统计时点前最后一个阶段事件。漏斗计算同批商机曾经到达各阶段的数量。阶段回退后，曾到达的阶段仍计入漏斗。
- 首次和最近渠道以关联线索的触点为依据，只使用在统计时点前已发生、已导入的记录。同一事件时间按触点编号排定。赢单额从时点对应的商机金额折算。
- 合同使用时点前最后一份签署版本。金额列反映已签署金额，合同和商机分别汇总。
- 旧版本升级时从阶段历史和金额变更审计恢复已知金额。旧数据若没有保存首次变更前的金额，该段时点的金额显示「待确认」，相关记录仍计入阶段与记录数。汇总中的「已折算」显示有金额依据的记录数。

## 权限与操作

集团经理只读当前有经理权限的快照公司。分公司销售按本公司和当前客户、业务负责人权限读取自己的记录。撤销公司权限或调换客户负责人后，旧快照的下钻、汇总与 CSV 都会收紧。导出不包含联系人联络信息。

JSON 接口使用 `report.fx`、`report.capture` 操作。查询 `GET /api.php?company=<公司编号>&resource=reports&id=<快照编号>`，可选 `scope_company`、`kind` 与 `stage`。CSV 地址为 `/export.php?company=<公司编号>&report=<快照编号>`。

`tests/management-reports.php` 在 MySQL 验证 AC-15 和 AC-16、三家公司合同来源、阶段回退、两类渠道归因、日元折算及撤权后导出。HTTP 测试补充报告页面、文件下载及精确业务过滤。
